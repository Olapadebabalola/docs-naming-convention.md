Northwind security groups will use the pattern `SEC-<Type>-<Name>`. The type identifies how the group is organized, such as `Dept` for a department or `Role` for a job function. For example, `SEC-Dept-Sales` is the department group for Sales. This makes each group’s purpose clear from its name.

Northwind user sign-in names will use the pattern `firstname.lastname@<your-tenant-domain>`. Names will be lowercase and consistent. If two people have the same name, I will add a middle initial or a number to keep their sign-in names unique.
